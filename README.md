# Leaditor

Editor de texto em blocos independente, offline, sem servidor. Baseado no Gutenberg (Isolated Block Editor), sem WordPress, sem CDN, sem build.

## Arquivos (5)

- `index.html` — interface completa
- `core.css` — estilos do editor
- `isolated-block-editor.css` — estilos adicionais
- `isolated-block-editor.js` — editor de blocos
- `react.production.min.js` + `react-dom.production.min.js` — React

## Como usar

Abra `index.html` diretamente no navegador (não precisa de servidor). Todo o processamento é local (edição, rascunho no `localStorage`, exportação HTML com CSS embutido).
